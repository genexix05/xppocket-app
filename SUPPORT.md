XP Pocket is a small independent project. There is no support desk. You can write to
[support@xppocket.app](mailto:support@xppocket.app) or open an issue on the GitHub issue tracker.

## Email

For questions about your account, XP Pocket Pro, cloud save, or a purchase, write to
[support@xppocket.app](mailto:support@xppocket.app). For privacy requests, see the
[privacy policy](https://xppocket.app/privacy).

## Report a game on GitHub

Open an issue on [GitHub](https://github.com/genexix05/xppocket-app/issues) when a game crashes,
renders wrong, or refuses to start. One issue per game. Include:

- The game title and the game version.
- The XP Pocket version, from **Settings → About**.
- Your device and iOS version.
- What you did, what you expected, and what happened.
- The log file, collected as described below.

A report with a log is much easier to fix. A report without one usually waits until the game can
be found and reproduced.

## Collect the logs

1. Go to **Settings → Advanced**, and turn on **Debug logs**. XP Pocket removes the older logs at
   the start of each session.
2. Start the game, and repeat the steps that fail.
3. Open the Files app, go to **On My iPhone → XP Pocket**, and share the newest log file. Attach it
   to the issue or send it by email.

## Suggest a feature

Open an issue with the word "idea" in the title. Say what you want to do, not how XP Pocket should
do it.
