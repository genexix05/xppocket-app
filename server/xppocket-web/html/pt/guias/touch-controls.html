Controlos táteis no XP Pocket

Os fan games de PC não trazem gamepad no ecrã. O XP Pocket adiciona layouts táteis que pode adaptar por jogo.

  1. Abra um jogo importado

    Os controlos aparecem sobre o jogo. Pause ou abra os ajustes de layout conforme a UI.

  2. Ajuste o layout ao título

    Mova, redimensione ou oculte botões. Guarde um perfil por jogo se quiser.

  3. Experimente layouts da comunidade

    A app pode listar packs na API pública. São overlays, não jogos.

  4. Jogue em ecrã inteiro

    Quando o layout encaixar, continue a jogar no dispositivo.

Perguntas frequentes

É preciso pagar pelos layouts?

Jogar e importar não exige conta. Funções Pro são opcionais.

Os layouts incluem jogos?

Não. Só mapas de botões. Você importa os jogos.

Funciona no iPad?

Sim.
