Como jogar Pokémon Añil no iPhone

Se já tem Pokémon Añil (ou outro fan game baseado em Essentials), pode carregá-lo no XP Pocket. A app só executa o que você importa.

  1. Use os seus ficheiros de Añil

    Tem de ter uma cópia de que tenha direitos. O XP Pocket não liga, não descarrega e não redistribui Pokémon Añil.

  2. Prepare a pasta ou o arquivo

    Tenha a pasta do jogo ou um arquivo compatível em Ficheiros / iCloud.

  3. Importe no XP Pocket

    Na biblioteca, adicione o jogo a partir do dispositivo.

  4. Jogue e guarde no dispositivo

    Abra Añil, configure o layout tátil e guarde localmente. Cloud save é opcional.
