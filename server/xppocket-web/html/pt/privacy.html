Política de privacidade

Última atualização: 24 de agosto de 2026

Responsável

XP Pocket (xppocket.app). Contacto: support@xppocket.app.

Resumo

Pode usar o XP Pocket sem conta. Se iniciar sessão com a Apple ou usar cloud save (Pro), alguns dados são enviados para os nossos servidores. Não vendemos dados pessoais nem usamos publicidade na app.

Dados no dispositivo

  • Preferências (definições, layouts táteis).
  • Jogos e saves que importa ou cria ao jogar.
  • Metadados de ficheiros usados pelo iOS.
  • Logs de diagnóstico opcionais, só locais, se os ativar.

Conta opcional (Sign in with Apple)

Se escolher iniciar sessão:

  • Recebemos um identificador de conta Apple.
  • Podemos receber um email (real ou Hide My Email).
  • Usamos isso para autenticá-lo e associar funções de conta (Pro, cloud save).

Cloud save (Pro, opcional)

Se enviar ou descarregar saves, o pacote e metadados do jogo ficam nos nossos servidores ligados à sua conta. Você controla quando enviar ou apagar. Não usamos os saves para publicidade nem os partilhamos com terceiros.

Layouts da comunidade

A app pode contactar api.xppocket.app para listar ou descarregar layouts. Não é necessária conta para navegar.

O que não fazemos

  • Sem SDK de analytics ou publicidade na versão atual.
  • Sem tracking entre apps.
  • Não vendemos dados pessoais.

Terceiros

O XP Pocket inclui software open source (mkxp-z, SDL, etc.). A Apple pode receber relatórios de crash anónimos se os ativar. O Sign in with Apple é operado pela Apple.

Conservação e direitos (UE)

Tratamos dados de conta e cloud save para prestar o serviço. Conservamos enquanto a conta existir ou até pedir eliminação. Contacte support@xppocket.app.

Menores

Não recolhemos dados de menores de forma intencional. Uso conforme a App Store.

Alterações

Publicaremos alterações nesta página com uma nova data.
