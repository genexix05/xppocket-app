Comment importer un jeu RPG Maker sur iPhone

XP Pocket transforme votre iPhone en lecteur mkxp‑z : vous importez le jeu, il reste dans la bibliothèque de l'appareil.

  1. Vérifiez le format

    Les projets RPG Maker XP, VX et VX Ace (RGSS) fonctionnent en général. Vous devez avoir les droits sur ces fichiers.

  2. Copiez le jeu sur l'appareil

    Utilisez AirDrop, iCloud Drive, Fichiers, etc. avant d'importer.

  3. Ajoutez depuis la bibliothèque

    Dans XP Pocket, utilisez ajouter et sélectionnez le dossier ou l'archive.

  4. Organisez et jouez

    Ouvrez le jeu dans la liste. Pas de catalogue distant de jeux.

FAQ

Faut-il un compte ?

Non pour importer et jouer. Sign in with Apple est optionnel.

Où sont stockés les jeux ?

Sur l'appareil, dans l'espace de l'app.

Puis-je importer un ZIP ?

Oui, si l'archive est un projet compatible.
