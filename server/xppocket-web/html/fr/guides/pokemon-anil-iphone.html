Comment jouer à Pokémon Añil sur iPhone

Si vous avez déjà Pokémon Añil (ou un autre fan game basé sur Essentials), vous pouvez le charger dans XP Pocket. L'app n'exécute que ce que vous importez.

  1. Utilisez vos propres fichiers Añil

    Vous devez disposer d'une copie dont vous avez les droits. XP Pocket ne lie pas, ne télécharge pas et ne redistribue pas Pokémon Añil.

  2. Préparez le dossier ou l'archive

    Ayez le dossier du jeu ou une archive compatible dans Fichiers / iCloud.

  3. Importez dans XP Pocket

    Dans la bibliothèque, ajoutez le jeu depuis l'appareil.

  4. Jouez et sauvegardez sur l'appareil

    Ouvrez Añil, réglez le layout tactile et sauvegardez en local. Le cloud save est optionnel.

FAQ

Puis-je télécharger Añil depuis XP Pocket ?

Non. Jamais. Vous importez uniquement des fichiers que vous avez déjà.

Est-ce affilié à Nintendo ?

Non. C'est un lecteur indépendant.

Ça marche pour d'autres fan games ?

Oui, s'ils sont compatibles RPG Maker / Essentials et que vous avez les droits.

Pokémon et les marques associées appartiennent à Nintendo, Game Freak et The Pokémon Company. XP Pocket n'est pas affilié. Nous n'incluons ni ne distribuons de jeux, ROMs ou assets protégés. L'app n'exécute que les fichiers que vous importez et dont vous avez les droits.
