Contrôles tactiles dans XP Pocket

Les fan games PC n'ont pas de manette à l'écran. XP Pocket ajoute des layouts tactiles que vous adaptez par jeu.

  1. Ouvrez un jeu importé

    Les contrôles s'affichent sur le jeu. Mettez en pause ou ouvrez les réglages de layout selon l'UI.

  2. Ajustez le layout au titre

    Déplacez, redimensionnez ou masquez des boutons. Enregistrez un profil par jeu si vous voulez.

  3. Essayez les layouts communautaires

    L'app peut lister des packs via l'API publique. Ce sont des overlays, pas des jeux.

  4. Jouez en plein écran

    Quand le layout convient, continuez sur l'appareil.

FAQ

Faut-il payer pour les layouts ?

Jouer et importer ne nécessitent pas de compte. Les fonctions Pro sont optionnelles.

Les layouts incluent-ils des jeux ?

Non. Uniquement des cartes de boutons. Vous importez les jeux.

Ça marche sur iPad ?

Oui.

Pokémon et les marques associées appartiennent à Nintendo, Game Freak et The Pokémon Company. XP Pocket n'est pas affilié. Nous n'incluons ni ne distribuons de jeux, ROMs ou assets protégés. L'app n'exécute que les fichiers que vous importez et dont vous avez les droits.
