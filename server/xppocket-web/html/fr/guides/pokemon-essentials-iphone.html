Comment jouer à Pokémon Essentials sur iPhone

XP Pocket est un lecteur iOS pour jeux RPG Maker et projets basés sur Pokémon Essentials. Vous apportez le dossier ou l'archive ; l'app ne télécharge ni n'inclut de titres.

  1. Préparez vos fichiers de jeu

    Il vous faut une copie du projet Essentials / RPG Maker XP dont vous avez les droits. XP Pocket ne propose pas de téléchargements de fan games ni d'assets protégés.

  2. Installez XP Pocket

    Une fois sur l'App Store, installez-le sur un iPhone ou iPad sous iOS 26 ou plus. Vous pouvez jouer sans compte.

  3. Importez le projet

    Ouvrez la bibliothèque et utilisez ajouter. Choisissez le dossier ou l'archive depuis Fichiers, iCloud Drive, etc.

  4. Jouez avec les contrôles tactiles

    Lancez le jeu et ajustez le layout tactile si besoin. Les sauvegardes restent sur l'appareil ; le cloud save est optionnel.

FAQ

XP Pocket inclut-il Pokémon Essentials ?

Non. C'est un lecteur : il exécute les projets que vous importez.

Quels moteurs / RGSS sont pris en charge ?

Le moteur mkxp‑z couvre RPG Maker XP, VX et VX Ace (RGSS).

Ça marche sur iPad ?

Oui. La même app sur iPhone et iPad.

Pokémon et les marques associées appartiennent à Nintendo, Game Freak et The Pokémon Company. XP Pocket n'est pas affilié. Nous n'incluons ni ne distribuons de jeux, ROMs ou assets protégés. L'app n'exécute que les fichiers que vous importez et dont vous avez les droits.
