Politique de confidentialité

Dernière mise à jour : 24 août 2026

Responsable

XP Pocket (xppocket.app). Contact : support@xppocket.app.

Résumé

Vous pouvez utiliser XP Pocket sans compte. Si vous vous connectez avec Apple ou utilisez la sauvegarde cloud (Pro), certaines données sont envoyées à nos serveurs pour fournir ce service. Nous ne vendons pas de données personnelles et n'affichons pas de publicité dans l'app.

Données sur l'appareil

  • Préférences (réglages, layouts tactiles).
  • Jeux et sauvegardes que vous importez ou créez en jouant.
  • Métadonnées de fichiers utilisées par iOS.
  • Journaux de diagnostic optionnels, uniquement locaux, si vous les activez.

Compte optionnel (Sign in with Apple)

Si vous choisissez de vous connecter :

  • Nous recevons un identifiant de compte Apple.
  • Nous pouvons recevoir une adresse e-mail (réelle ou Masquer mon e-mail), selon votre choix.
  • Nous l'utilisons pour vous authentifier et associer les fonctions de compte (Pro, cloud save).

Cloud save (Pro, optionnel)

Si vous téléversez ou téléchargez des sauvegardes, le pack et les métadonnées du jeu sont stockés sur nos serveurs liés à votre compte. Vous contrôlez quand envoyer ou supprimer. Nous n'utilisons pas vos sauvegardes pour la publicité et ne les partageons pas avec des tiers.

Layouts communautaires

L'app peut contacter api.xppocket.app pour lister ou télécharger des layouts. Aucun compte n'est requis pour parcourir.

Ce que nous ne faisons pas

  • Pas de SDK d'analytics ou de publicité dans la version actuelle.
  • Pas de suivi inter-apps.
  • Nous ne vendons pas de données personnelles.

Tiers

XP Pocket inclut des logiciels open source (mkxp-z, SDL, etc.). Apple peut recevoir des rapports de plantage anonymes si vous les activez. Sign in with Apple est géré par Apple.

Conservation et droits (UE)

Nous traitons les données de compte et de cloud save pour fournir le service demandé. Nous les conservons tant que le compte existe ou jusqu'à une demande de suppression. Contactez support@xppocket.app.

Mineurs

Nous ne collectons pas volontairement de données de mineurs. L'usage suit les classifications App Store.

Modifications

Nous publierons les changements sur cette page avec une nouvelle date.
