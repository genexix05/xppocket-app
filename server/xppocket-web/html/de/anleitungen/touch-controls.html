Touch-Steuerung in XP Pocket

PC-Fan-Games haben kein On-Screen-Gamepad. XP Pocket ergänzt Touch-Layouts, die du pro Spiel anpassen kannst.

  1. Importiertes Spiel öffnen

    Die Steuerung liegt über dem Spiel. Pause oder Layout-Einstellungen je nach UI öffnen.

  2. Layout an den Titel anpassen

    Buttons verschieben, skalieren oder ausblenden. Optional Profil pro Spiel speichern.

  3. Community-Layouts testen

    Die App kann Packs über die öffentliche API listen. Es sind Overlays, keine Spiele.

  4. Vollbild spielen

    Wenn das Layout passt, weiter on‑device spielen.

FAQ

Muss ich für Layouts zahlen?

Spielen und Importieren brauchen kein Konto. Pro-Funktionen sind optional.

Enthalten Layouts Spiele?

Nein. Nur Button-Maps. Du importierst die Spiele.

Geht es auf dem iPad?

Ja.

Pokémon und verwandte Marken gehören Nintendo, Game Freak und The Pokémon Company. XP Pocket ist nicht verbunden. Wir enthalten und verteilen keine Spiele, ROMs oder urheberrechtlich geschützte Assets. Die App führt nur Dateien aus, die du importierst und nutzen darfst.
