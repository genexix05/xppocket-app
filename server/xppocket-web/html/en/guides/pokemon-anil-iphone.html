How to play Pokémon Añil on iPhone

If you already have Pokémon Añil (or another Essentials-based fan game), you can load it in XP Pocket. The app only runs what you import; it does not offer the game.

  1. Use your own Añil files

    You must have a copy you have rights to. XP Pocket does not link, download, or redistribute Pokémon Añil or any other title.

  2. Prepare the folder or archive

    Have the game folder or a compatible archive ready in Files / iCloud. Essentials-style projects on RPG Maker XP are the usual case.

  3. Import into XP Pocket

    In the library, add the game from your device. It appears like any other imported title.

  4. Play and save on device

    Open Añil, set up the touch layout, and save locally. Cloud save is optional with Sign in with Apple and Pro.
