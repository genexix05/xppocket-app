How to import an RPG Maker game on iPhone

XP Pocket turns your iPhone into an mkxp‑z player: you import the game, it stays in the on‑device library, and you launch it whenever you want.

  1. Check the format

    RPG Maker XP, VX, and VX Ace (RGSS) projects usually work, including many fan games and Essentials titles. You must have rights to those files.

  2. Copy the game to iPhone or iPad

    Use AirDrop, iCloud Drive, Files, or another method so the folder or archive is on the device before importing.

  3. Add from the library

    In XP Pocket, tap add and select the folder or archive. The title appears in your local library.

  4. Organize and play

    Open the game from the list. You can keep multiple imported titles; there is no remote game catalog.

FAQ

Do I need an account?

Not to import and play. Sign in with Apple is optional (cloud save and Pro).

Where are games stored?

On device, in the app’s space. You control what you import and delete.

Can I import a ZIP?

Yes, if the archive is a compatible project. You can also import an unzipped folder.
